# Write a WIG file

Write a WIG file

## Usage

``` r
write_wig(x, file)
```

## Arguments

- x:

  A GRanges object

- file:

  File name, URL or connection specifying a file to write x to.
  Compressed files with extensions such as '.gz' are handled
  automatically.

## Value

The write function returns a WIGFile invisibly.
